# Demo video

`StageLens_live_demo_silent.mp4` (1 min 47 s, 1080p, no audio) is the Stage I demo: the real pipeline running on a PC CPU, before / after comparisons on real stage footage, the known limit, and the benchmark numbers.

- It is **not a real-time recording**. The CPU prototype processes about 5.7 FPS; the footage was processed first and is played back at normal speed (the video says so on screen).
- Nothing in it was measured on the UGen300.
- Video files are ignored by git. Published on YouTube: https://youtu.be/A79SVF0easU (also linked from the main README).
- `extras/` has two labelled before / after clips that still contain the original performance music; do not publish them unless the music licence is cleared.
